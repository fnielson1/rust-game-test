## 2. Flatten a curve into sample points

- [x] 2.1 Add a `TOLERANCE` constant (start at `0.5` world units) and `MIN_SUBDIVISIONS`/`MAX_SUBDIVISIONS` bounds (`1` and `64`), documenting that the tolerance is what makes facets invisible at normal zoom
- [x] 2.2 Implement `subdivision_count()` on `Segment`: use `subdivisions` when declared, otherwise `ceil(sqrt(|P0 - 2*P1 + P2| / (4 * TOLERANCE)))`, clamped to the bounds in 2.1; document the closed form as coming from the quadratic's constant second derivative
- [x] 2.3 Implement `sample_points()` returning `n + 1` points along the curve at uniform steps in `t`, evaluating the quadratic Bézier; a straight segment returns just its two endpoints
- [x] 2.4 Implement a tangent-at-`t` (or finite-difference) helper and derive the unit normal at each sample point from it
- [x] 2.5 Reject the too-sharp-for-thickness case: compute the tightest radius of curvature over the samples and fail validation when it falls below `thickness / 2.0`, so the inner offset edge can never fold through itself
- [x] 2.6 Add unit tests covering: no control point yields two points; a symmetric control point yields a curve peaking at half the control offset; swapping `start`/`end` yields the same point set reversed; a collinear control point yields a straight line; subdivision count rises with curve size and is clamped at both ends
